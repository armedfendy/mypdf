Pertanyaan yang Sering Diajukan

Jawaban untuk hal-hal yang paling sering ditanyakan tentang mypdf.id.

Apakah file saya aman? Apakah file di-upload ke server?

File Anda tidak pernah di-upload. Semua proses berjalan di dalam browser, di perangkat Anda sendiri, sehingga kami tidak bisa melihat, menyimpan, atau membagikan isi dokumen Anda. Kode sumber mypdf.id terbuka untuk umum, jadi hal ini bisa diperiksa oleh siapa saja.

Apakah mypdf.id benar-benar gratis?

Ya. Semua alat gratis, tanpa pendaftaran, tanpa batas jumlah file, dan tanpa watermark pada hasilnya. Biaya situs ditutup dari iklan yang tampil di halaman.

Kenapa ada iklan? Apakah iklan bisa melihat file saya?

Iklan Google AdSense adalah cara kami menjaga mypdf.id tetap gratis. Iklan tidak punya akses ke file Anda, karena file hanya diproses di memori browser. Iklan dapat menggunakan cookie; penjelasannya ada di Kebijakan Privasi.

Apakah saya perlu membuat akun?

Tidak. Buka halaman alat yang Anda butuhkan, pilih file, dan hasilnya bisa langsung diunduh.

Berapa batas ukuran file?

Tidak ada batas dari sisi kami, karena tidak ada server yang menerima file. Batasnya ditentukan oleh memori perangkat dan browser Anda. File berukuran ratusan megabyte biasanya lancar di laptop, tetapi bisa lambat atau gagal di HP dengan RAM kecil.

Bagaimana cara mengecilkan PDF untuk daftar CPNS atau beasiswa?

Gunakan alat Kompres PDF. Untuk target ukuran tertentu, tersedia halaman khusus seperti kompres ke 200 KB, 500 KB, atau 1 MB. Jika hasilnya masih terlalu besar, coba tingkat kompresi yang lebih tinggi atau ubah dokumen menjadi hitam putih.

Apakah bisa dipakai di HP?

Bisa. mypdf.id berjalan di browser modern seperti Chrome, Safari, Firefox, dan Edge, baik di Android, iPhone, Windows, macOS, maupun Linux. Untuk file besar, laptop atau komputer akan terasa lebih cepat.

Apakah bisa dipakai tanpa internet?

Internet dibutuhkan untuk membuka halaman alat pertama kali. Setelah halaman dan komponennya termuat, proses file berjalan di perangkat Anda sehingga sebagian besar alat tetap bisa dipakai walau koneksi terputus.

Apa hubungan mypdf.id dengan BentoPDF?

mypdf.id dibangun dari BentoPDF, proyek sumber terbuka berlisensi AGPL-3.0. Kami menerjemahkan dan menyesuaikannya untuk pengguna Indonesia, dan seluruh perubahan kami juga terbuka di GitHub. mypdf.id dikelola secara terpisah dan bukan layanan resmi BentoPDF.

Saya menemukan masalah. Ke mana saya melapor?

Kirim email ke kontak@mypdf.id atau buat laporan di halaman GitHub mypdf.id. Sertakan nama alat, browser, dan perangkat yang Anda pakai. Jangan lampirkan dokumen pribadi.
