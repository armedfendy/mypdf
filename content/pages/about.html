Tentang mypdf.id Alat PDF yang menghormati privasi Anda.

mypdf.id adalah kumpulan alat PDF gratis berbahasa Indonesia. Semua proses berjalan langsung di browser Anda, jadi file tidak pernah di-upload ke server mana pun.

Kenapa mypdf.id dibuat

Hampir semua orang pernah perlu mengolah PDF: menggabungkan scan KTP dan KK, mengecilkan ukuran file agar lolos batas unggah pendaftaran CPNS atau beasiswa, atau menandatangani dokumen kerja. Sayangnya, banyak layanan PDF online mengharuskan file diunggah ke server mereka, padahal dokumen seperti itu berisi data pribadi.

mypdf.id hadir sebagai alternatif: alat yang sama praktisnya, tetapi file Anda tetap berada di perangkat Anda dari awal sampai akhir.

Cara kerjanya

Setiap alat di mypdf.id dijalankan oleh JavaScript dan WebAssembly di dalam browser Anda. Saat Anda memilih file, file tersebut dibaca dan diproses oleh perangkat Anda sendiri, lalu hasilnya langsung diunduh. Tidak ada salinan yang dikirim ke server kami, dan kami tidak bisa melihat isi dokumen Anda.

Karena itu, kecepatan proses bergantung pada kemampuan perangkat Anda. File yang sangat besar mungkin butuh waktu lebih lama di HP dengan memori terbatas.

Gratis, dibiayai iklan

Semua alat bisa dipakai gratis, tanpa pendaftaran, tanpa batas jumlah file, dan tanpa watermark. Biaya operasional situs ditutup dari iklan Google AdSense yang tampil di halaman. Iklan tidak pernah mendapat akses ke file Anda. Penjelasan lengkap tentang data yang terkait iklan ada di Kebijakan Privasi.

Sumber terbuka, berbasis BentoPDF

mypdf.id dibangun di atas BentoPDF, proyek sumber terbuka karya Alam yang dirilis dengan lisensi AGPL-3.0. Kami menerjemahkan, menyesuaikan, dan mengelolanya untuk pengguna Indonesia. Seluruh kode sumber mypdf.id, termasuk semua perubahan kami, terbuka untuk umum di github.com/armedfendy/mypdf, sehingga siapa pun bisa memeriksa bahwa file memang tidak pernah dikirim ke server.

Siapa di balik mypdf.id

mypdf.id dikelola oleh pengembang independen di Indonesia. Punya saran, menemukan bug, atau butuh alat yang belum ada? Kami senang mendengarnya lewat halaman Kontak.
