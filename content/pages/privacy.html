Kebijakan Privasi

Terakhir diperbarui: 16 Oktober 2026

1. Ringkasan

Kebijakan Privasi ini menjelaskan komitmen privasi mypdf.id ("kami") saat Anda menggunakan situs https://mypdf.id. Prinsip utama kami sederhana: kami tidak mengumpulkan atau menyimpan data pribadi Anda, dan file yang Anda olah tidak pernah dikirim ke server kami. Layanan ini berjalan tanpa pendaftaran akun. Penjelasan mengenai pemrosesan lokal di browser serta layanan pihak ketiga (seperti penayangan iklan dan analitik anonim) diuraikan secara transparan di bawah ini.

2. File dan dokumen Anda

Seluruh alat PDF di mypdf.id berjalan langsung di browser Anda (client-side) menggunakan teknologi JavaScript dan WebAssembly. File yang Anda pilih dibaca dan diproses sepenuhnya di dalam memori perangkat Anda sendiri, lalu hasilnya disimpan langsung ke perangkat Anda. Kami tidak pernah menerima, melihat, menyimpan, atau membagikan file, nama file, maupun metadata dokumen Anda. Begitu Anda menutup tab browser, seluruh data pemrosesan file tersebut otomatis terhapus dari memori.

Untuk beberapa fitur, browser Anda mungkin mengunduh komponen pemrosesan tambahan (seperti modul WebAssembly atau font) dari jaringan distribusi konten (CDN) seperti jsDelivr. Proses ini murni satu arah untuk mengunduh komponen program ke browser Anda: file maupun dokumen Anda tidak pernah dikirim ke layanan CDN tersebut.

3. Iklan dan cookie

mypdf.id sendiri tidak menggunakan cookie pelacak (tracking cookies). Namun, untuk membiayai operasional layanan gratis ini, kami menampilkan ruang iklan dari jaringan pihak ketiga, yaitu Adsterra.

  • Isolasi Keamanan: Iklan dimuat di dalam bingkai (sandboxed iframe) terpisah yang diisolasi secara teknis dari aplikasi utama. Skrip iklan tidak memiliki akses untuk membaca file Anda, memori pemrosesan PDF, maupun mengalihkan halaman yang sedang Anda gunakan.
  • Cookie Pihak Ketiga: Adsterra dan mitranya dapat menggunakan cookie atau teknologi serupa di dalam bingkai iklan mereka untuk menayangkan iklan, membatasi frekuensi tayang, mengukur kinerja iklan, dan mencegah klik palsu (fraud). Pemrosesan ini dilakukan langsung oleh Adsterra dan diatur sepenuhnya oleh Kebijakan Privasi Adsterra.
  • Kendali Anda: Anda dapat memblokir atau menghapus cookie pihak ketiga kapan saja melalui pengaturan browser Anda tanpa mengganggu fungsi alat PDF di situs ini.
  • Tanpa Pembagian Data: Karena kami tidak mengumpulkan data pribadi maupun menerima file Anda, tidak ada data atau dokumen apa pun dari kami yang dapat dijual atau dibagikan kepada pengiklan.

4. Statistik kunjungan

Kami menggunakan Cloudflare Web Analytics untuk memahami trafik situs secara agregat dan anonim: seperti total jumlah kunjungan, halaman alat yang paling sering digunakan, jenis perangkat secara umum, serta negara asal pengunjung. Layanan analitik ini berfokus pada privasi: tidak menggunakan cookie, tidak melacak perilaku individu lintas situs (fingerprinting), dan tidak mengumpulkan data pribadi maupun isi file Anda. Kami hanya melihat laporan angka statistik umum untuk keperluan pemeliharaan situs dan tidak dapat mengidentifikasi pengunjung secara perorangan.

5. Data teknis oleh penyedia hosting

Situs ini di-hosting di Cloudflare. Seperti layanan web pada umumnya, Cloudflare memproses data teknis seperti alamat IP dan jenis browser untuk mengirimkan halaman serta melindungi situs dari serangan.

6. Penyimpanan di browser Anda

Beberapa pengaturan, misalnya preferensi tampilan atau pengaturan alat, disimpan di penyimpanan lokal browser (localStorage) agar tidak perlu diatur ulang. Data ini tetap berada di perangkat Anda dan bisa dihapus kapan saja melalui pengaturan browser.

7. Email yang Anda kirim

Jika Anda menghubungi kami melalui email, mohon jangan melampirkan dokumen pribadi dalam email.

8. Hak Anda

Sesuai Undang-Undang Nomor 27 Tahun 2022 tentang Pelindungan Data Pribadi, Anda berhak meminta akses, perbaikan, atau penghapusan data pribadi Anda yang kami simpan, misalnya email yang pernah Anda kirim. Untuk cookie iklan yang dikelola Adsterra dan mitranya, Anda dapat memblokir atau menghapusnya melalui pengaturan browser, atau menggunakan hak Anda sesuai kebijakan privasi Adsterra (lihat bagian 3).

9. Anak-anak

mypdf.id tidak ditujukan untuk mengumpulkan data dari anak-anak, dan kami tidak dengan sengaja mengumpulkan data pribadi dari mereka.

10. Tautan ke situs lain

Situs ini dapat berisi tautan ke situs pihak ketiga, termasuk iklan. Kebijakan privasi situs tersebut berlaku saat Anda mengunjunginya, dan kami tidak bertanggung jawab atas praktik privasinya.

11. Perubahan kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Tanggal pembaruan terakhir tercantum di bagian atas halaman ini.
