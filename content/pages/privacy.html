Kebijakan Privasi

Terakhir diperbarui: 8 Oktober 2026

1. Ringkasan

Kebijakan ini menjelaskan bagaimana mypdf.id ("kami") menangani data saat Anda memakai situs https://mypdf.id. Prinsip utamanya sederhana: file yang Anda olah tidak pernah dikirim ke server kami. Data lain yang terkait dengan situs, seperti cookie iklan dan statistik kunjungan, dijelaskan di bawah ini.

2. File dan dokumen Anda

Semua alat PDF di mypdf.id berjalan di browser Anda menggunakan JavaScript dan WebAssembly. File yang Anda pilih dibaca dan diproses di perangkat Anda sendiri, lalu hasilnya diunduh langsung ke perangkat Anda. Kami tidak menerima, melihat, menyimpan, atau membagikan isi file Anda, dan tidak ada salinan file yang tersimpan di server.

Untuk beberapa alat, browser Anda mengunduh komponen pemrosesan (misalnya modul WebAssembly) dari layanan CDN jsDelivr. Yang diunduh hanyalah komponen program; file Anda tidak pernah dikirim ke CDN tersebut.

3. Iklan Google AdSense dan cookie

mypdf.id menampilkan iklan dari Google AdSense untuk membiayai layanan gratis ini.

  • Vendor pihak ketiga, termasuk Google, menggunakan cookie untuk menayangkan iklan berdasarkan kunjungan Anda sebelumnya ke situs ini atau situs lain.
  • Penggunaan cookie iklan memungkinkan Google dan mitranya menayangkan iklan kepada Anda berdasarkan kunjungan Anda ke situs ini dan/atau situs lain di internet.
  • Anda dapat menonaktifkan iklan yang dipersonalisasi melalui Setelan Iklan Google, atau menonaktifkan cookie vendor pihak ketiga untuk iklan yang dipersonalisasi melalui www.aboutads.info.
  • Penjelasan lengkap tentang cara Google menggunakan data dari situs partner tersedia di policies.google.com/technologies/partner-sites.

Pengunjung dari wilayah tertentu (misalnya Uni Eropa dan Inggris) akan diminta persetujuan sebelum cookie iklan digunakan.

4. Statistik kunjungan

Kami memakai layanan analitik, seperti Cloudflare Web Analytics dan Google Analytics, untuk mengetahui jumlah pengunjung, halaman yang dibuka, jenis perangkat, dan asal kunjungan secara umum. Data ini membantu kami memperbaiki situs. Data analitik tidak berisi isi file Anda. Google Analytics dapat menggunakan cookie; Cloudflare Web Analytics tidak menggunakan cookie.

5. Data teknis oleh penyedia hosting

Situs ini di-hosting di Cloudflare. Seperti layanan web pada umumnya, Cloudflare memproses data teknis seperti alamat IP dan jenis browser untuk mengirimkan halaman serta melindungi situs dari serangan.

6. Penyimpanan di browser Anda

Beberapa pengaturan, misalnya preferensi tampilan atau pengaturan alat, disimpan di penyimpanan lokal browser (localStorage) agar tidak perlu diatur ulang. Data ini tetap berada di perangkat Anda dan bisa dihapus kapan saja melalui pengaturan browser.

7. Email yang Anda kirim

Jika Anda menghubungi kami melalui email, kami menyimpan alamat email dan isi pesan Anda hanya untuk membalas dan menindaklanjuti pesan tersebut. Mohon jangan melampirkan dokumen pribadi dalam email.

8. Hak Anda

Sesuai Undang-Undang Nomor 27 Tahun 2022 tentang Pelindungan Data Pribadi, Anda berhak meminta akses, perbaikan, atau penghapusan data pribadi Anda yang kami simpan, misalnya email yang pernah Anda kirim. Untuk data yang dikelola Google (cookie iklan dan Google Analytics), Anda dapat mengaturnya melalui tautan pada bagian 3 atau melalui pengaturan akun Google Anda.

9. Anak-anak

mypdf.id tidak ditujukan untuk mengumpulkan data dari anak-anak, dan kami tidak dengan sengaja mengumpulkan data pribadi dari mereka.

10. Tautan ke situs lain

Situs ini dapat berisi tautan ke situs pihak ketiga, termasuk iklan. Kebijakan privasi situs tersebut berlaku saat Anda mengunjunginya, dan kami tidak bertanggung jawab atas praktik privasinya.

11. Perubahan kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Tanggal pembaruan terakhir tercantum di bagian atas halaman ini.
