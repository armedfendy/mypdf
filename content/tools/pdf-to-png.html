Ubah PDF ke PNG di mypdf.id: setiap halaman PDF dijadikan gambar PNG yang tajam, cocok untuk teks, tabel, dan diagram yang perlu tetap jelas. Gratis, tanpa daftar, dan file tidak di-upload ke server.

Cara Mengubah PDF ke PNG

1

Pilih file PDF

Klik kotak di atas atau seret satu file PDF. Kalau file berkata sandi, Anda akan diminta memasukkannya.

2

Atur skala gambar

Skala 2.0x (bawaan) sudah tajam untuk layar. Naikkan hingga 3.0x untuk gambar lebih detail.

3

Klik Konversi

Setiap halaman dirender menjadi PNG langsung di browser Anda.

4

Unduh gambarnya

PDF satu halaman menghasilkan satu PNG. PDF berhalaman banyak diunduh sebagai ZIP berisi page_1.png, page_2.png, dan seterusnya.

PNG atau JPG?

PNG menyimpan gambar tanpa kehilangan kualitas, sehingga teks kecil, garis tabel, dan diagram tetap tajam. Konsekuensinya, ukuran filenya lebih besar. Untuk dikirim lewat chat atau diunggah ke portal dengan batas ukuran, PDF ke JPG menghasilkan file yang jauh lebih kecil.

Hanya butuh beberapa halaman? Ambil dulu halamannya dengan Ekstrak Halaman, lalu konversi file yang lebih kecil itu.

Pertanyaan Seputar PDF ke PNG

Berapa resolusi gambar PNG-nya?

Skala 1.0x setara 72 piksel per inci. Skala bawaan 2.0x menggandakannya, dan 3.0x setara sekitar 216 piksel per inci. Halaman A4 pada 2.0x menjadi sekitar 1190 x 1684 piksel.

Apakah latar belakangnya transparan?

Tidak. Halaman digambar di atas latar putih, jadi area kosong tetap berwarna putih.

Bisakah hanya halaman tertentu yang dikonversi?

Semua halaman dikonversi. Ambil dulu halaman yang dibutuhkan dengan Ekstrak Halaman, lalu konversi file hasilnya.

Kenapa ukuran file PNG besar?

PNG tidak memakai kompresi yang mengurangi kualitas, jadi satu halaman bisa berukuran beberapa MB, terutama untuk hasil scan dan foto. Gunakan PDF ke JPG bila ukuran file lebih penting.

Apakah isian formulir dan stabilo ikut tampil?

Ya. Tanda yang terlihat di halaman seperti stabilo, stempel, dan isian formulir ikut tergambar. Isi komentar pop-up tidak ikut, hanya ikon catatannya.

Apakah file saya di-upload ke server?

Tidak. Semua proses berjalan di browser, di perangkat Anda sendiri. Dokumen tidak pernah dikirim ke server mypdf.id maupun pihak lain.

Apakah bisa dipakai di HP?

Bisa, di Chrome, Safari, atau browser modern lain di Android maupun iPhone. Untuk file besar, laptop atau komputer akan terasa lebih cepat.
