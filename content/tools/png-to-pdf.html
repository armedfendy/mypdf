Ubah PNG ke PDF di mypdf.id: satukan screenshot, diagram, atau gambar PNG menjadi satu file PDF. Pilih kualitas Tinggi agar teks dan garis tetap tajam. Gratis, tanpa daftar, tanpa watermark, dan gambar tidak di-upload.

Cara Mengubah PNG ke PDF

1

Pilih gambar PNG

Klik kotak di atas atau seret satu atau beberapa file PNG. Setiap gambar menjadi satu halaman.

2

Pilih kualitas

Tinggi menyimpan PNG apa adanya tanpa kompresi. Sedang dan Rendah mengubahnya ke JPEG dan memperkecil gambar besar agar file lebih ringan.

3

Klik Konversi ke PDF

Semua gambar disatukan menjadi satu PDF sesuai urutan pada daftar.

4

Unduh PDF-nya

File PDF langsung tersimpan di perangkat Anda.

Memilih Kualitas yang Tepat

  • Tinggi: untuk screenshot, diagram, dan dokumen berteks kecil. Gambar disimpan tanpa kompresi, dan area transparan tetap transparan.
  • Sedang: JPEG kualitas 75%, sisi terpanjang maksimal 2500 piksel. Cocok untuk foto.
  • Rendah: JPEG kualitas 50%, sisi terpanjang maksimal 1500 piksel. File paling kecil.

Ukuran halaman mengikuti ukuran gambar. Butuh halaman A4 yang seragam? Lanjutkan dengan Perbaiki Ukuran Halaman. Untuk foto JPG, gunakan JPG ke PDF.

Pertanyaan Seputar PNG ke PDF

Kualitas mana yang cocok untuk screenshot?

Tinggi. Screenshot dan diagram punya tepi tajam dan teks kecil, dan kompresi JPEG pada Sedang atau Rendah membuatnya buram.

Bagaimana dengan bagian gambar yang transparan?

Pada kualitas Tinggi, bagian transparan tetap transparan dan tampil putih di aplikasi pembaca. Sedang dan Rendah memakai JPEG yang tidak mendukung transparansi.

Bisakah beberapa PNG dijadikan satu PDF?

Bisa. Setiap file menjadi satu halaman sesuai urutan pada daftar, dan hasilnya selalu satu file PDF.

Kenapa ukuran PDF hampir sama dengan total ukuran PNG?

Pada kualitas Tinggi, data PNG disimpan tanpa diubah. Pilih Sedang atau Rendah, atau kecilkan hasilnya dengan Kompres PDF.

Berapa ukuran halaman PDF-nya?

Ukuran halaman mengikuti ukuran piksel gambar, jadi screenshot lebar menghasilkan halaman lebar. Gunakan Perbaiki Ukuran Halaman bila butuh A4.

Apakah file saya di-upload ke server?

Tidak. Semua proses berjalan di browser, di perangkat Anda sendiri. Dokumen tidak pernah dikirim ke server mypdf.id maupun pihak lain.

Apakah bisa dipakai di HP?

Bisa, di Chrome, Safari, atau browser modern lain di Android maupun iPhone. Untuk file besar, laptop atau komputer akan terasa lebih cepat.
