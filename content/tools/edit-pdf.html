Edit PDF di mypdf.id: sorot dan garis bawahi teks, beri komentar, tambahkan teks, gambar, bentuk, coretan bebas, dan sensor (redaksi) informasi sensitif secara permanen. Gratis, tanpa daftar, dan dokumen diproses di browser tanpa di-upload.

Cara Mengedit PDF

1

Pilih file PDF

Klik kotak di atas atau seret file PDF. Hingga 10 dokumen bisa dibuka sekaligus, masing-masing di tab sendiri.

2

Pilih alat di toolbar

Sorot, garis bawah, coret, pena, kotak teks, komentar, bentuk, gambar, atau redaksi untuk menyensor bagian tertentu.

3

Tandai dan tambahkan isi

Klik atau seret di halaman untuk menambahkan anotasi. Perubahan langsung terlihat di layar.

4

Unduh PDF hasil edit

Klik tombol unduh. Perubahan tidak tersimpan otomatis, jadi unduh dulu sebelum menutup halaman.

Mengubah Teks yang Sudah Ada

Editor ini bekerja di atas halaman: menambahkan sorotan, komentar, gambar, bentuk, kotak teks baru, dan redaksi. Untuk mengganti kalimat yang sudah ada di dokumen, gunakan Edit Teks PDF, yang memungkinkan Anda mengklik paragraf lalu mengubahnya langsung.

PDF hasil scan hanya berisi gambar, jadi teksnya tidak bisa disorot. Jalankan OCR PDF lebih dulu, atau tandai secara visual dengan pena dan kotak.

Pertanyaan Seputar Edit PDF

Bisakah mengubah teks yang sudah ada di PDF?

Editor ini untuk menambahkan isi di atas halaman. Untuk menulis ulang teks yang sudah ada, gunakan Edit Teks PDF.

Apakah hasil edit terlihat di Adobe Reader atau Chrome?

Ya. Sorotan, komentar, bentuk, dan coretan disimpan sebagai anotasi PDF standar. Kotak teks ditulis ke halaman sebagai teks biasa, sehingga tampil sama di semua aplikasi.

Apakah redaksi benar-benar menghapus informasi?

Ya. Redaksi menghapus isi di bawah area yang ditandai dari file, bukan sekadar menutupinya dengan kotak hitam, sehingga teksnya tidak bisa disalin atau dicari lagi. Periksa file hasil unduhan sebelum dibagikan.

Apakah perubahan tersimpan otomatis?

Tidak. Perubahan hanya ada di memori browser sampai Anda mengunduh PDF hasil edit. Menutup atau memuat ulang halaman akan menghapus perubahan.

Kenapa teks di PDF scan tidak bisa disorot?

Sorot, garis bawah, dan coret membutuhkan teks asli, sedangkan halaman scan hanya gambar. Jalankan OCR PDF dulu agar ada lapisan teks.

Apakah file saya di-upload ke server?

Tidak. Semua proses berjalan di browser, di perangkat Anda sendiri. Dokumen tidak pernah dikirim ke server mypdf.id maupun pihak lain.

Apakah bisa dipakai di HP?

Bisa, di Chrome, Safari, atau browser modern lain di Android maupun iPhone. Untuk file besar, laptop atau komputer akan terasa lebih cepat.
