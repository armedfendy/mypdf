Pertanyaan yang Sering Diajukan

Bagaimana cara menggabungkan beberapa PDF menjadi satu?

Tambahkan dua file atau lebih ke Gabung PDF lalu seret sesuai urutan. Mode file menggabungkan dokumen utuh dengan rentang halaman opsional per file, sedangkan mode halaman menampilkan setiap halaman sebagai thumbnail agar urutannya bisa disusun persis.

Apa saja cara memisahkan PDF?

Pisah PDF punya enam mode: rentang halaman, pilih lewat thumbnail, halaman genap atau ganjil, satu file per halaman, berdasarkan bookmark, dan setiap N halaman. Beberapa file hasil diunduh dalam satu ZIP.

Apa beda Pisah PDF, Ekstrak Halaman, dan Hapus Halaman?

Ekstrak Halaman menyimpan halaman yang Anda sebut sebagai file terpisah, Hapus Halaman membuang halaman yang Anda sebut dan menyimpan sisanya, dan Pisah PDF memecah satu dokumen menjadi beberapa file.

Bisakah menyusun ulang atau menggandakan halaman?

Bisa. Atur Halaman menampilkan setiap halaman sebagai thumbnail yang bisa diseret, dengan tombol gandakan dan hapus. Anda juga bisa menulis urutan lengkap seperti 3, 1, 2, 4.

Hasil scan dua sisi saya urutannya terpisah depan dan belakang. Bagaimana memperbaikinya?

Gunakan Gabung Selang-seling untuk menyelang-nyeling halaman dari dua file, misalnya file halaman depan dan file halaman belakang, sehingga urutannya kembali depan 1, belakang 1, depan 2, dan seterusnya.

Apakah kualitas halaman berubah setelah digabung atau dipisah?

Tidak. Halaman disalin apa adanya tanpa dikompres ulang, jadi teks, gambar, dan tautan tetap sama seperti aslinya.

Apakah file saya di-upload ke server?

Tidak. Semua alat di halaman ini berjalan di browser Anda. File dibaca dari perangkat Anda dan hasilnya langsung disimpan kembali, tanpa melewati server.
