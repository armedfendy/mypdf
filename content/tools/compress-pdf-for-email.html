Kompres PDF untuk email agar lampiran tidak ditolak karena terlalu besar. Gratis, tanpa daftar, dan file diproses di browser Anda tanpa di-upload.

Cara Kompres PDF untuk Email

1

Pilih file PDF

Klik kotak di atas atau seret satu atau beberapa file PDF. File tidak di-upload; semuanya diproses di browser Anda.

2

Pilih algoritma

Condense cocok untuk sebagian besar dokumen dan tetap menjaga teks bisa dipilih. Photon mengubah halaman menjadi gambar, cocok untuk hasil scan atau PDF penuh foto.

3

Pilih tingkat kompresi

Untuk lampiran email, Seimbang biasanya sudah cukup. Pilih Agresif bila total lampiran masih melebihi batas server email.

4

Unduh dan cek ukurannya

Pesan hasil menampilkan ukuran sebelum dan sesudah kompresi. Beberapa file sekaligus diunduh sebagai satu file ZIP.

Berapa Batas Lampiran Email?

Gmail membatasi lampiran hingga 25 MB per email, dan banyak server email kantor menerapkan batas yang lebih kecil, misalnya 10 MB. Lampiran yang lebih kecil juga lebih cepat dikirim dan dibuka penerima, terutama di koneksi seluler.

Mengompres PDF sebelum dikirim lebih praktis daripada membagi dokumen menjadi beberapa email.

Tips Agar Lampiran PDF Tidak Ditolak

  • Untuk dokumen kerja biasa, tingkat Seimbang sudah cukup.
  • Kirim banyak PDF sekaligus? Kompres semuanya dalam satu proses, lalu lampirkan file ZIP hasilnya.
  • Untuk laporan yang sangat besar, gunakan Agresif atau bagi dokumen dengan alat Pisah PDF.

Pertanyaan Seputar Kompres PDF untuk Email

Berapa ukuran ideal PDF untuk lampiran email?

Usahakan di bawah 10 MB agar aman untuk hampir semua server email. Untuk dikirim ke banyak penerima, di bawah 2 MB jauh lebih nyaman.

Bisakah mengompres beberapa PDF untuk satu email?

Bisa. Pilih semua file sekaligus; hasilnya diunduh sebagai satu file ZIP yang bisa langsung dilampirkan.

Apakah teks di PDF masih bisa dipilih setelah dikompres?

Dengan Condense, ya. Gambar dikompres ulang dan font diringkas tanpa menyentuh lapisan teks, jadi teks, pencarian, dan tautan tetap berfungsi. Photon mengubah setiap halaman menjadi gambar JPEG, sehingga teks tidak bisa lagi dipilih dan tautan tidak aktif.

Apakah file saya di-upload ke server?

Tidak. Condense menjalankan mesin PyMuPDF yang dikompilasi ke WebAssembly, dan Photon memakai mesin render halaman milik browser. Semua proses terjadi di perangkat Anda, jadi dokumen pribadi seperti KTP, ijazah, atau slip gaji tidak pernah dikirim ke mana pun.
