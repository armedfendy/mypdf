Kompres PDF ke 200 KB untuk memenuhi batas unggah portal pendaftaran online. Gratis, tanpa daftar, dan file diproses langsung di browser Anda tanpa di-upload.

Cara Kompres PDF ke 200 KB

1

Pilih file PDF

Klik kotak di atas atau seret satu atau beberapa file PDF. File tidak di-upload; semuanya diproses di browser Anda.

2

Pilih algoritma

Condense cocok untuk sebagian besar dokumen dan tetap menjaga teks bisa dipilih. Photon mengubah halaman menjadi gambar, cocok untuk hasil scan atau PDF penuh foto.

3

Pilih tingkat kompresi

Untuk target 200 KB, mulai dari Seimbang. Bila masih terlalu besar, pilih Agresif dan aktifkan Konversi ke Grayscale.

4

Unduh dan cek ukurannya

Pesan hasil menampilkan ukuran sebelum dan sesudah kompresi. Beberapa file sekaligus diunduh sebagai satu file ZIP.

Kapan Batas 200 KB Dipakai?

Batas 200 KB sering ditemui di portal pendaftaran seleksi kerja, beasiswa, ujian masuk, dan berbagai layanan online, terutama untuk dokumen seperti scan KTP, ijazah, transkrip, atau surat pernyataan. Batas setiap portal bisa berbeda, jadi pastikan Anda membaca ketentuannya.

Dibanding 100 KB, target 200 KB lebih longgar: sebagian besar dokumen sehari-hari bisa mencapainya dengan tingkat Seimbang atau Agresif tanpa penurunan kualitas yang terlihat.

Tips Agar PDF di Bawah 200 KB

  • Mulai dengan Seimbang, lalu naik ke Agresif bila hasilnya masih di atas 200 KB.
  • Untuk scan berwarna yang tidak membutuhkan warna, aktifkan Konversi ke Grayscale.
  • Setiap halaman scan bisa bernilai ratusan kilobyte, jadi hapus halaman kosong atau yang tidak diminta lebih dulu.
  • Perlu menyatukan beberapa dokumen dalam satu file? Gabungkan PDF dulu, baru kompres hasilnya.

Pertanyaan Seputar Kompres PDF ke 200 KB

Seperti apa kualitas PDF di 200 KB?

Dokumen ketikan terlihat sama seperti aslinya. Scan tetap terbaca di tingkat Agresif; foto di dalam PDF sedikit lebih lembut tetapi masih jelas di layar.

Portal meminta di bawah 200 KB, padahal file saya 10 MB. Bisa?

Bisa untuk dokumen satu sampai tiga halaman. File sebesar itu biasanya berasal dari scan resolusi tinggi, yang justru paling banyak menyusut saat dikompres. Kalau masih di atas 200 KB, kurangi jumlah halaman atau gunakan Photon.

Apakah teks di PDF masih bisa dipilih setelah dikompres?

Dengan Condense, ya. Gambar dikompres ulang dan font diringkas tanpa menyentuh lapisan teks, jadi teks, pencarian, dan tautan tetap berfungsi. Photon mengubah setiap halaman menjadi gambar JPEG, sehingga teks tidak bisa lagi dipilih dan tautan tidak aktif.

Apakah file saya di-upload ke server?

Tidak. Condense menjalankan mesin PyMuPDF yang dikompilasi ke WebAssembly, dan Photon memakai mesin render halaman milik browser. Semua proses terjadi di perangkat Anda, jadi dokumen pribadi seperti KTP, ijazah, atau slip gaji tidak pernah dikirim ke mana pun.
