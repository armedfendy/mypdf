Ubah PDF ke Excel di mypdf.id: ambil tabel dari laporan, rekening koran, atau faktur PDF menjadi file XLSX yang bisa diolah. Setiap tabel masuk ke sheet sendiri. Gratis, tanpa daftar, dan data keuangan Anda tidak di-upload ke server.

Cara Mengubah PDF ke Excel

1

Pilih file PDF

Klik kotak di atas atau seret satu file PDF yang berisi tabel. Kalau file berkata sandi, Anda akan diminta memasukkannya.

2

Klik Konversi

Semua halaman diperiksa dan setiap tabel yang ditemukan diambil isinya.

3

Unduh file Excel

Hasilnya satu file XLSX. Setiap tabel menjadi sheet sendiri dengan nama seperti Table 1 (Page 3), sehingga asal halamannya jelas.

Agar Tabel Terbaca dengan Baik

  • Tabel dikenali dari strukturnya, seperti garis tabel dan sel yang sejajar. Teks yang hanya disusun dengan spasi sering tidak terdeteksi sebagai tabel.
  • PDF hasil scan hanya berisi gambar. Jalankan OCR PDF dulu agar teksnya bisa dibaca.
  • Yang dipindahkan hanya isi sel. Warna, garis, lebar kolom, dan sel gabungan tidak ikut.
  • Angka kadang masuk sebagai teks. Bila kolom tidak bisa dijumlahkan, pilih kolom itu lalu gunakan fitur Convert to Number di Excel.

Pertanyaan Seputar PDF ke Excel

Kenapa muncul pesan tabel tidak ditemukan?

Alat ini mencari struktur tabel seperti garis dan sel yang sejajar. Teks berkolom yang hanya dipisah spasi, atau tabel di dalam gambar scan, tidak terdeteksi. Untuk scan, jalankan OCR PDF dulu; untuk teks biasa, gunakan PDF ke Teks.

Bagaimana jika ada banyak tabel?

Setiap tabel menjadi sheet sendiri, diberi nama sesuai urutan dan halaman asalnya. PDF dengan satu tabel menghasilkan satu sheet.

Apakah format, warna, dan sel gabungan ikut?

Tidak. Hanya teks di setiap sel yang dipindahkan. Font, warna, garis, lebar kolom, dan sel gabungan perlu dirapikan lagi di Excel.

Bisakah hanya halaman tertentu yang dikonversi?

Semua halaman diperiksa. Bila hanya butuh satu tabel, ambil dulu halamannya dengan Ekstrak Halaman, lalu konversi file hasilnya.

Apakah rekening koran dan faktur saya aman?

Ya. Deteksi tabel dan pembuatan file Excel berjalan di browser Anda, jadi dokumen keuangan tidak pernah dikirim ke server.

Apakah bisa dipakai di HP?

Bisa, di Chrome, Safari, atau browser modern lain di Android maupun iPhone. Untuk file besar, laptop atau komputer akan terasa lebih cepat.
