Kompres PDF ke 2 MB dengan kualitas gambar tetap tinggi. Cocok untuk portfolio, laporan bergambar, dan dokumen yang akan dicetak. Gratis dan diproses di browser.

Cara Kompres PDF ke 2 MB

1

Pilih file PDF

Klik kotak di atas atau seret satu atau beberapa file PDF. File tidak di-upload; semuanya diproses di browser Anda.

2

Pilih algoritma

Condense cocok untuk sebagian besar dokumen dan tetap menjaga teks bisa dipilih. Photon mengubah halaman menjadi gambar, cocok untuk hasil scan atau PDF penuh foto.

3

Pilih tingkat kompresi

Untuk target 2 MB, tingkat Ringan biasanya sudah cukup dan menjaga kualitas foto. Gunakan Seimbang untuk dokumen bergambar yang panjang.

4

Unduh dan cek ukurannya

Pesan hasil menampilkan ukuran sebelum dan sesudah kompresi. Beberapa file sekaligus diunduh sebagai satu file ZIP.

Kapan Target 2 MB Cocok?

Batas 2 MB sering dipakai untuk dokumen yang lebih kaya gambar, seperti portfolio desain, laporan kegiatan bergambar, proposal, atau berkas pendukung lomba dan beasiswa. Ukuran ini memungkinkan foto tetap tajam.

Kebanyakan dokumen bisa mencapai 2 MB hanya dengan tingkat Ringan, sehingga hampir tidak ada penurunan kualitas.

Tips Agar PDF di Bawah 2 MB

  • Mulai dari tingkat Ringan untuk menjaga kualitas foto.
  • Gunakan Seimbang untuk laporan dengan puluhan halaman bergambar.
  • Hindari Photon untuk dokumen yang teksnya perlu bisa disalin.

Pertanyaan Seputar Kompres PDF ke 2 MB

Apakah portfolio bergambar bisa di bawah 2 MB?

Umumnya bisa dengan tingkat Ringan atau Seimbang. Untuk portfolio puluhan halaman dengan foto besar, pertimbangkan membaginya menjadi beberapa file.

Apakah hasilnya tetap bagus untuk dicetak?

Ya, tingkat Ringan memakai kualitas 90% dan 150 DPI, cukup untuk cetakan dokumen dan foto ukuran kecil.

Apakah teks di PDF masih bisa dipilih setelah dikompres?

Dengan Condense, ya. Gambar dikompres ulang dan font diringkas tanpa menyentuh lapisan teks, jadi teks, pencarian, dan tautan tetap berfungsi. Photon mengubah setiap halaman menjadi gambar JPEG, sehingga teks tidak bisa lagi dipilih dan tautan tidak aktif.

Apakah file saya di-upload ke server?

Tidak. Condense menjalankan mesin PyMuPDF yang dikompilasi ke WebAssembly, dan Photon memakai mesin render halaman milik browser. Semua proses terjadi di perangkat Anda, jadi dokumen pribadi seperti KTP, ijazah, atau slip gaji tidak pernah dikirim ke mana pun.
