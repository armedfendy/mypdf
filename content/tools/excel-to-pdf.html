Ubah Excel ke PDF di mypdf.id: konversi spreadsheet XLSX, XLS, ODS, atau CSV menjadi PDF lengkap dengan format sel, grafik, dan semua sheet. Gratis, tanpa daftar, dan data Anda diproses di browser tanpa di-upload.

Cara Mengubah Excel ke PDF

1

Pilih file spreadsheet

Klik kotak di atas atau seret file XLSX, XLS, ODS, atau CSV. Bisa beberapa file sekaligus.

2

Tunggu mesin konversi siap

Saat pertama kali dipakai, browser mengunduh mesin konversi berbasis LibreOffice. Setelah itu konversi berikutnya lebih cepat.

3

Klik Konversi ke PDF

Setiap sheet ditata mengikuti pengaturan halaman, area cetak, dan skala yang tersimpan di file.

4

Unduh hasilnya

Satu file diunduh sebagai PDF. Beberapa file diunduh sekaligus dalam satu ZIP.

Agar Tabel Lebar Tidak Terpotong

Alat ini mengikuti pengaturan cetak di dalam file. Sebelum mengonversi, buka file di Excel atau LibreOffice Calc lalu atur:

  • Orientasi halaman landscape untuk tabel yang lebar.
  • Area cetak (Print Area) bila hanya sebagian sheet yang perlu dicetak.
  • Skala "Fit to width" atau "Sesuaikan ke 1 halaman lebar" agar kolom tidak terpotong.

Tampilan Print Preview di Excel adalah gambaran paling dekat dengan hasil PDF-nya. Untuk sebaliknya, gunakan PDF ke Excel.

Pertanyaan Seputar Excel ke PDF

Format apa saja yang didukung?

XLSX, XLS, ODS dari LibreOffice Calc, dan CSV. Beberapa format bisa dicampur dan dikonversi sekaligus.

Apakah semua sheet ikut dikonversi?

Ya. Semua sheet masuk ke PDF, masing-masing mengikuti pengaturan halaman dan area cetaknya sendiri.

Apakah rumus dan grafik ikut?

Grafik ikut tergambar di PDF. Rumus tampil sebagai hasil hitungannya. Warna sel, garis, font, dan format angka tetap dipertahankan.

Bagaimana agar tabel lebar tidak terpotong ke beberapa halaman?

Atur orientasi landscape dan skala Fit to width di Excel atau LibreOffice Calc sebelum mengonversi. Alat ini membaca pengaturan tersebut dari file.

Kenapa konversi pertama agak lama?

Mesin konversi berbasis LibreOffice berukuran sekitar 75 MB dan perlu diunduh sekali ke browser Anda. Setelah itu mesin sudah siap, sehingga konversi berikutnya jauh lebih cepat.

Apakah data keuangan saya aman?

Ya. Mesin LibreOffice berjalan di browser Anda, jadi spreadsheet dibuka dan dikonversi di perangkat sendiri. Data tidak pernah dikirim ke server.

Apakah bisa dipakai di HP?

Bisa, di Chrome, Safari, atau browser modern lain di Android maupun iPhone. Untuk file besar, laptop atau komputer akan terasa lebih cepat.
