Kompres PDF ke 500 KB agar file cukup kecil untuk diunggah, sambil tetap menjaga gambar dan teks tetap tajam. Gratis dan diproses di browser Anda.

Cara Kompres PDF ke 500 KB

1

Pilih file PDF

Klik kotak di atas atau seret satu atau beberapa file PDF. File tidak di-upload; semuanya diproses di browser Anda.

2

Pilih algoritma

Condense cocok untuk sebagian besar dokumen dan tetap menjaga teks bisa dipilih. Photon mengubah halaman menjadi gambar, cocok untuk hasil scan atau PDF penuh foto.

3

Pilih tingkat kompresi

Untuk target 500 KB, Seimbang biasanya sudah cukup. Pilih Ringan bila dokumen akan dicetak, atau Agresif untuk dokumen penuh foto.

4

Unduh dan cek ukurannya

Pesan hasil menampilkan ukuran sebelum dan sesudah kompresi. Beberapa file sekaligus diunduh sebagai satu file ZIP.

Kapan Target 500 KB Cocok?

Batas 500 KB sering dipakai untuk dokumen berhalaman lebih banyak, seperti CV beserta lampiran, sertifikat, atau berkas administrasi beberapa halaman. Ukuran ini memberi ruang cukup untuk menjaga gambar tetap jelas.

Untuk sebagian besar dokumen, tingkat Seimbang sudah cukup untuk mencapai 500 KB, sehingga hasilnya tetap nyaman dibaca maupun dicetak.

Tips Agar PDF di Bawah 500 KB

  • Coba Ringan lebih dulu bila dokumen akan dicetak; turun ke Seimbang bila masih di atas 500 KB.
  • Dokumen berisi banyak foto berwarna biasanya perlu tingkat Agresif.
  • Hapus halaman yang tidak diperlukan sebelum dikompres untuk hasil lebih kecil.

Pertanyaan Seputar Kompres PDF ke 500 KB

Apakah 500 KB cukup untuk dokumen beberapa halaman?

Umumnya cukup untuk 5 sampai 10 halaman dokumen ketikan, dan beberapa halaman scan bila memakai tingkat Seimbang atau Agresif.

Apakah hasilnya masih layak dicetak?

Dengan tingkat Ringan atau Seimbang, ya. Ringan memakai 150 DPI yang cukup untuk cetakan dokumen biasa.

Apakah teks di PDF masih bisa dipilih setelah dikompres?

Dengan Condense, ya. Gambar dikompres ulang dan font diringkas tanpa menyentuh lapisan teks, jadi teks, pencarian, dan tautan tetap berfungsi. Photon mengubah setiap halaman menjadi gambar JPEG, sehingga teks tidak bisa lagi dipilih dan tautan tidak aktif.

Apakah file saya di-upload ke server?

Tidak. Condense menjalankan mesin PyMuPDF yang dikompilasi ke WebAssembly, dan Photon memakai mesin render halaman milik browser. Semua proses terjadi di perangkat Anda, jadi dokumen pribadi seperti KTP, ijazah, atau slip gaji tidak pernah dikirim ke mana pun.
