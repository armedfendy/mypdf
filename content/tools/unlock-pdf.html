Buka kunci PDF di mypdf.id untuk menghapus password dari PDF milik Anda, misalnya agar bisa digabung, diunggah ke sistem yang menolak file terenkripsi, atau diarsipkan. Kata sandi saat ini tetap diperlukan. Gratis, dan file maupun kata sandi tidak di-upload.

Cara Menghapus Password PDF

1

Pilih file PDF

Klik kotak di atas atau seret satu atau beberapa PDF. Beberapa file bisa diproses sekaligus bila kata sandinya sama.

2

Masukkan kata sandi

Gunakan kata sandi untuk membuka file atau kata sandi pemilik.

3

Klik Buka Kunci

Enkripsi dihapus seluruhnya sehingga tidak ada batasan yang tersisa.

4

Unduh hasilnya

Satu file diunduh dengan nama aslinya. Beberapa file diunduh sekaligus dalam satu ZIP.

Kapan Perlu Menghapus Password PDF?

  • Portal atau aplikasi arsip menolak file yang terenkripsi.
  • PDF terkunci perlu digabung dengan file lain lewat Gabung PDF.
  • Dokumen akan diarsipkan jangka panjang dan kata sandinya tidak diperlukan lagi.

PDF bisa dibuka tetapi tidak bisa dicetak atau disalin? Itu batasan izin, bukan kata sandi pembuka. Gunakan Hapus Pembatasan.

Pertanyaan Seputar Buka Kunci PDF

Bisakah menghapus password yang saya tidak tahu?

Tidak. Alat ini memerlukan kata sandi yang benar dan tidak membobol, menebak, atau mencoba-coba kata sandi.

Kata sandi mana yang bisa dipakai?

Kata sandi untuk membuka file maupun kata sandi pemilik. Hasilnya salinan tanpa enkripsi dan tanpa batasan.

Bisakah membuka beberapa PDF sekaligus?

Bisa, asalkan kata sandinya sama. Masukkan kata sandi sekali, lalu semua file diunduh dalam satu ZIP. File dengan kata sandi berbeda perlu diproses terpisah.

Kenapa muncul pesan kata sandi salah?

Kata sandi tidak cocok dengan file. Periksa Caps Lock dan spasi di akhir, dan pastikan memakai kata sandi untuk file tersebut. File yang rusak bisa dicoba dengan alat Perbaiki PDF.

Apakah isi dokumen berubah?

Tidak. Halaman, teks, gambar, formulir, dan bookmark tetap utuh. Hanya lapisan enkripsi yang dihapus. Kunci lagi dengan Kunci PDF bila perlu kata sandi baru.

Apakah file atau kata sandi saya dikirim ke server?

Tidak. Proses buka kunci berjalan di browser Anda, jadi file dan kata sandi tetap di perangkat.

Apakah bisa dipakai di HP?

Bisa, di Chrome, Safari, atau browser modern lain di Android maupun iPhone. Untuk file besar, laptop atau komputer akan terasa lebih cepat.
