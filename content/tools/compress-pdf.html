Kompres PDF di mypdf.id untuk mengecilkan ukuran file tanpa mengorbankan keterbacaan. Gratis, tanpa daftar, tanpa batas jumlah file, dan file Anda tidak pernah di-upload ke server.

Cara Kompres PDF Online

1

Pilih file PDF

Klik kotak di atas atau seret satu atau beberapa file PDF. File tidak di-upload; semuanya diproses di browser Anda.

2

Pilih algoritma

Condense cocok untuk sebagian besar dokumen dan tetap menjaga teks bisa dipilih. Photon mengubah halaman menjadi gambar, cocok untuk hasil scan atau PDF penuh foto.

3

Pilih tingkat kompresi

Ringan menjaga kualitas paling baik, Seimbang (bawaan) cocok untuk dibaca di layar, sedangkan Agresif dan Ekstrem menghasilkan file paling kecil. Centang Konversi ke Grayscale untuk menghemat lebih banyak.

4

Unduh dan cek ukurannya

Pesan hasil menampilkan ukuran sebelum dan sesudah kompresi. Beberapa file sekaligus diunduh sebagai satu file ZIP.

Seberapa Kecil PDF Bisa Dikompres?

Sebagian besar ukuran PDF berasal dari gambar, jadi dokumen hasil scan atau yang berisi banyak foto biasanya bisa dikecilkan jauh. Dokumen yang hampir seluruhnya teks sudah kecil sejak awal, sehingga penghematannya lebih sedikit. Dengan algoritma Condense, setiap tingkat bekerja seperti ini:

  • Ringan: kualitas JPEG 90% dan 150 DPI, paling aman untuk dicetak.
  • Seimbang: kualitas 75% dan 96 DPI, nyaman dibaca di layar.
  • Agresif: kualitas 50% dan 72 DPI, untuk batas unggah yang ketat.
  • Ekstrem: kualitas 30% dan 60 DPI, ukuran paling kecil.

Pertanyaan Seputar Kompres PDF

Kenapa PDF saya masih besar setelah dikompres?

Kalau gambar di dalam PDF sedikit atau sudah kecil, tidak banyak yang bisa dikompres, dan pesan hasil akan memberi tahu bila ukurannya tidak berkurang. Coba tingkat yang lebih kuat seperti Agresif, aktifkan Konversi ke Grayscale, atau pakai Photon bila file berupa hasil scan.

Apakah teks di PDF masih bisa dipilih setelah dikompres?

Dengan Condense, ya. Gambar dikompres ulang dan font diringkas tanpa menyentuh lapisan teks, jadi teks, pencarian, dan tautan tetap berfungsi. Photon mengubah setiap halaman menjadi gambar JPEG, sehingga teks tidak bisa lagi dipilih dan tautan tidak aktif.

Apakah kompresi menghapus metadata PDF?

Tergantung tingkatnya. Ringan mempertahankan informasi dokumen, sedangkan Seimbang, Agresif, dan Ekstrem menghapusnya. Anda bisa mengatur sendiri lewat kotak centang Hapus metadata di Pengaturan Kustom.

Bisakah PDF hasil scan dikompres?

Bisa, dan biasanya hasilnya bagus karena scan berupa gambar satu halaman penuh. Mulai dengan Condense di tingkat Seimbang atau Agresif. Pakai Photon hanya bila butuh file lebih kecil lagi dan tidak masalah kehilangan lapisan teks OCR.

Apa fungsi Pengaturan Kustom?

Pengaturan Kustom menggantikan preset untuk algoritma Condense: Kualitas Output (1 sampai 100) mengatur kualitas JPEG, Ubah Ukuran Gambar Ke menentukan target DPI, dan Hanya Proses Di Atas melewati gambar yang sudah di bawah DPI tersebut.

Bisakah mengompres banyak PDF sekaligus?

Bisa. Pilih beberapa file sekaligus; semuanya dikompres dengan pengaturan yang sama dan diunduh sebagai satu file ZIP.

Apakah file saya di-upload ke server?

Tidak. Condense menjalankan mesin PyMuPDF yang dikompilasi ke WebAssembly, dan Photon memakai mesin render halaman milik browser. Semua proses terjadi di perangkat Anda, jadi dokumen pribadi seperti KTP, ijazah, atau slip gaji tidak pernah dikirim ke mana pun.
