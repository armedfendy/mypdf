Tambah nomor halaman ke PDF di mypdf.id: cetak nomor di bawah atau atas halaman, dengan format 1 atau 1 / 12. Cocok untuk skripsi, laporan, makalah, dan berkas lamaran. Gratis, tanpa daftar, dan file tidak di-upload ke server.

Cara Menambahkan Nomor Halaman ke PDF

1

Pilih file PDF

Klik kotak di atas atau seret satu file PDF.

2

Pilih posisi nomor

Enam pilihan: bawah tengah, bawah kiri, bawah kanan, atas tengah, atas kiri, atau atas kanan.

3

Atur format dan tampilan

Pilih nomor saja atau format halaman X dari Y (contoh 3 / 12), lalu atur ukuran huruf dan warnanya.

4

Unduh hasilnya

PDF bernomor halaman langsung tersimpan di perangkat Anda.

Halaman Sampul Tanpa Nomor

Alat ini selalu mulai menomori dari halaman pertama. Kalau sampul atau halaman judul tidak boleh bernomor, pisahkan dulu halaman sampul dengan Pisah PDF, beri nomor pada sisanya, lalu satukan lagi dengan Gabung PDF.

Butuh tulisan bebas seperti "Halaman 3 dari 12" atau teks tambahan di kepala dan kaki halaman? Gunakan Header & Footer.

Pertanyaan Seputar Nomor Halaman PDF

Di mana saja nomor halaman bisa diletakkan?

Di enam posisi: bawah tengah, bawah kiri, bawah kanan, atas tengah, atas kiri, dan atas kanan. Jarak dari tepi menyesuaikan ukuran halaman secara otomatis.

Bisakah menampilkan total halaman seperti 3 / 12?

Bisa. Pilih format halaman X dari Y. Untuk tulisan bebas seperti "Halaman 3 dari 12", gunakan alat Header & Footer.

Bisakah mulai menomori dari halaman kedua?

Tidak langsung. Pisahkan halaman sampul, beri nomor pada halaman lainnya, lalu gabungkan kembali.

Font apa yang dipakai?

Helvetica, dengan ukuran 6 sampai 72 poin dan warna bebas. Jenis hurufnya tidak bisa diganti.

Apakah nomor halaman bisa dihapus nanti?

Nomor digambar langsung ke halaman, jadi tampil di semua aplikasi dan ikut tercetak, tetapi tidak bisa dimatikan lagi. Simpan file asli tanpa nomor.

Bagaimana dengan dokumen yang ukuran halamannya campur?

Setiap halaman diukur sendiri, jadi dokumen campuran A4 dan F4, atau tegak dan landscape, tetap mendapat nomor di posisi yang benar.

Apakah file saya di-upload ke server?

Tidak. Semua proses berjalan di browser, di perangkat Anda sendiri. Dokumen tidak pernah dikirim ke server mypdf.id maupun pihak lain.

Apakah bisa dipakai di HP?

Bisa, di Chrome, Safari, atau browser modern lain di Android maupun iPhone. Untuk file besar, laptop atau komputer akan terasa lebih cepat.
