Kunci PDF dengan password di mypdf.id: lindungi dokumen dengan enkripsi AES 256-bit sehingga hanya orang yang tahu kata sandinya yang bisa membuka. Bisa juga membatasi cetak, salin, dan edit. Gratis, dan file maupun kata sandi tidak pernah di-upload.

Cara Mengunci PDF dengan Password

1

Pilih file PDF

Klik kotak di atas atau seret satu file PDF.

2

Isi kata sandi pengguna

Kata sandi ini wajib dan harus diketik siapa pun yang ingin membuka file.

3

Isi kata sandi pemilik (opsional)

Bila diisi dengan kata sandi berbeda, PDF juga dibatasi: orang yang hanya tahu kata sandi pengguna tidak bisa mencetak, menyalin, atau mengedit.

4

Unduh PDF terkunci

File terenkripsi langsung tersimpan. Kirim kata sandinya lewat jalur berbeda dari file, misalnya lewat telepon.

Tips Membuat Kata Sandi PDF

  • Gunakan minimal 12 karakter, gabungan huruf, angka, dan simbol. Kekuatan perlindungan bergantung pada kata sandi Anda.
  • Simpan kata sandi di tempat aman. Kata sandi yang lupa tidak bisa dipulihkan, oleh siapa pun.
  • Simpan salinan PDF asli tanpa kata sandi untuk arsip pribadi.
  • Ingin membatasi cetak dan salin tanpa perlu kata sandi untuk membuka? Gunakan Ubah Izin.

Pertanyaan Seputar Kunci PDF

Apa beda kata sandi pengguna dan kata sandi pemilik?

Kata sandi pengguna wajib dan dipakai untuk membuka file. Kata sandi pemilik opsional; bila diisi berbeda, PDF juga diberi batasan sehingga orang yang membuka dengan kata sandi pengguna tidak bisa mencetak, menyalin, mengedit, atau mengubah halaman.

Enkripsi apa yang dipakai?

AES 256-bit sesuai standar enkripsi PDF 2.0. Tidak ada pilihan enkripsi yang lebih lemah.

Bagaimana kalau saya lupa kata sandinya?

Tidak ada cara memulihkannya. mypdf.id tidak menyimpan file maupun kata sandi Anda. Simpan kata sandi baik-baik dan simpan salinan asli tanpa kata sandi.

Bagaimana cara menghapus kata sandinya nanti?

Buka file dengan alat Buka Kunci PDF, masukkan kata sandinya, lalu unduh salinan tanpa enkripsi. Kata sandi tetap diperlukan.

Apakah PDF terkunci bisa dibuka di semua aplikasi?

Ya, di semua aplikasi pembaca PDF modern seperti Adobe Reader, Chrome, Edge, Firefox, dan aplikasi PDF di HP. Hanya aplikasi yang sangat lama yang mungkin menolak.

Apakah file atau kata sandi saya dikirim ke server?

Tidak. Enkripsi dilakukan di browser Anda, jadi dokumen dan kata sandi tidak pernah keluar dari perangkat.

Apakah bisa dipakai di HP?

Bisa, di Chrome, Safari, atau browser modern lain di Android maupun iPhone. Untuk file besar, laptop atau komputer akan terasa lebih cepat.
