Pisah PDF di mypdf.id untuk mengambil halaman tertentu, memisahkan setiap halaman menjadi file sendiri, atau membagi dokumen panjang menjadi beberapa bagian. Gratis, tanpa daftar, dan file tidak di-upload ke server.

Cara Memisahkan PDF

1

Pilih file PDF

Klik kotak di atas atau seret satu file PDF ke dalamnya.

2

Pilih mode pemisahan

Ambil rentang halaman, pisah halaman genap atau ganjil, pisah setiap halaman, pilih halaman lewat thumbnail, pisah berdasarkan bookmark, atau setiap N halaman.

3

Tentukan halamannya

Contoh: tulis 1-3, 7 untuk mengambil halaman 1 sampai 3 dan halaman 7. Pilih apakah hasilnya satu PDF gabungan atau satu PDF per rentang.

4

Unduh hasilnya

Satu file langsung terunduh sebagai PDF. Beberapa file diunduh sekaligus dalam satu ZIP.

Kapan Perlu Memisahkan PDF?

  • Mengambil satu lembar saja dari dokumen panjang, misalnya halaman KTP dari kumpulan scan berkas.
  • Memecah laporan atau buku elektronik menjadi beberapa bab agar ukuran tiap file lebih kecil.
  • Memisahkan scan dua sisi menjadi halaman genap dan ganjil.
  • Menyiapkan file per dokumen untuk portal pendaftaran yang meminta unggahan terpisah.

Setelah dipisah, file yang masih terlalu besar bisa dikecilkan dengan Kompres PDF.

Pertanyaan Seputar Pisah PDF

Bagaimana cara mengambil beberapa halaman sekaligus?

Pilih mode Ambil Berdasarkan Rentang Halaman, lalu tulis nomor dan rentang halaman dipisah koma, misalnya 1-3, 7, 12-15. Pilih Satu PDF gabungan bila semua halaman itu ingin disatukan dalam satu file.

Bisakah setiap halaman dijadikan file PDF sendiri?

Bisa. Pilih mode Pisah Setiap Halaman Menjadi File Sendiri. Semua halaman disimpan sebagai PDF terpisah dan diunduh dalam satu file ZIP.

Apa itu pisah berdasarkan bookmark?

Kalau PDF punya daftar isi (bookmark), dokumen bisa dipecah di setiap bookmark, misalnya per bab. Anda bisa memilih tingkat bookmark yang dijadikan titik pemisahan.

Apakah kualitas halaman berubah setelah dipisah?

Tidak. Halaman disalin apa adanya tanpa dikompres ulang, jadi teks, gambar, dan tautan tetap sama seperti aslinya.

Apakah file saya di-upload ke server?

Tidak. Semua proses berjalan di browser, di perangkat Anda sendiri. Dokumen tidak pernah dikirim ke server mypdf.id maupun pihak lain.

Apakah bisa dipakai di HP?

Bisa, di Chrome, Safari, atau browser modern lain di Android maupun iPhone. Untuk file besar, laptop atau komputer akan terasa lebih cepat.
