Ratakan (flatten) PDF di mypdf.id untuk mengunci isian formulir, tanda tangan, komentar, dan stempel ke dalam halaman sehingga tidak bisa diubah lagi. Cocok sebelum mengirim formulir yang sudah diisi. Gratis, tanpa daftar, dan file tidak di-upload.

Cara Meratakan PDF

1

Pilih file PDF

Klik kotak di atas atau seret satu atau beberapa PDF yang formulirnya sudah diisi.

2

Klik Ratakan PDF

Kolom formulir, kotak centang, komentar, dan anotasi lain disatukan ke isi halaman.

3

Unduh hasilnya

Satu file diunduh dengan awalan "flattened_" di namanya. Beberapa file diunduh sekaligus dalam satu ZIP.

Kapan Perlu Meratakan PDF?

  • Setelah mengisi formulir pendaftaran, agar jawaban tidak bisa diubah penerima.
  • Setelah menempelkan gambar tanda tangan, agar tidak bisa dipindah atau dihapus.
  • Saat formulir tampil berbeda di aplikasi lain; setelah diratakan, tampilannya sama di semua aplikasi.

Ratakan dulu, baru tanda tangani secara digital. Meratakan setelah tanda tangan digital akan membuat dokumen dianggap sudah diubah. Simpan juga file aslinya, karena PDF yang sudah diratakan tidak bisa dikembalikan.

Pertanyaan Seputar Ratakan PDF

Apa yang terjadi saat PDF diratakan?

Kolom formulir, kotak centang, pilihan, kolom tanda tangan, komentar, sorotan, stempel, dan coretan disatukan ke isi halaman. Tampilannya sama, tetapi tidak bisa diedit, dipindah, atau dihapus.

Apakah teks masih bisa dipilih dan dicari?

Ya. Halaman tidak diubah menjadi gambar. Teks, gambar, bookmark, dan ukuran halaman tetap seperti semula.

Kenapa muncul pesan formulir tidak ditemukan?

Pesan itu muncul bila PDF punya anotasi tetapi tidak punya kolom formulir. Bukan kesalahan; anotasinya tetap diratakan dan file tetap diunduh.

Apakah tautan masih bisa diklik?

Tautan termasuk anotasi, jadi bisa tidak berfungsi lagi meskipun teksnya tetap terlihat.

Bisakah meratakan beberapa PDF sekaligus?

Bisa. Pilih beberapa file, lalu semuanya diunduh dalam satu ZIP.

Apakah file saya di-upload ke server?

Tidak. Semua proses berjalan di browser, di perangkat Anda sendiri. Dokumen tidak pernah dikirim ke server mypdf.id maupun pihak lain.

Apakah bisa dipakai di HP?

Bisa, di Chrome, Safari, atau browser modern lain di Android maupun iPhone. Untuk file besar, laptop atau komputer akan terasa lebih cepat.
