Ekstrak halaman PDF di mypdf.id untuk mengambil halaman tertentu dari dokumen panjang, misalnya halaman KTP, ijazah, atau lampiran dari kumpulan scan. Setiap halaman disimpan sebagai PDF sendiri. Gratis, tanpa daftar, dan file tidak di-upload.

Cara Mengekstrak Halaman PDF

1

Pilih file PDF

Klik kotak di atas atau seret satu file PDF. Jumlah halamannya tampil di samping nama file.

2

Tulis halaman yang diambil

Pisahkan dengan koma, misalnya 2, 4-6, 9. Penomoran dimulai dari 1.

3

Klik Ekstrak

Halaman disalin apa adanya tanpa mengubah kualitas.

4

Unduh file ZIP

Setiap halaman menjadi PDF sendiri, misalnya laporan_page_4.pdf, dan semuanya diunduh dalam satu ZIP.

Ekstrak, Hapus, atau Pisah?

  • Ekstrak Halaman: setiap halaman yang dipilih menjadi file PDF sendiri.
  • Hapus Halaman: butuh satu PDF yang hanya berisi halaman tertentu? Hapus halaman lainnya.
  • Pisah PDF: memecah dokumen menjadi beberapa bagian berdasarkan rentang, bookmark, atau setiap N halaman, termasuk opsi menggabungkan rentang menjadi satu file.

Pertanyaan Seputar Ekstrak Halaman PDF

Apakah hasilnya satu PDF atau beberapa file?

Beberapa file. Setiap halaman yang dipilih menjadi PDF satu halaman, dan semuanya diunduh dalam satu ZIP. Untuk satu PDF berisi halaman tertentu saja, gunakan Hapus Halaman atau Pisah PDF.

Apakah kualitasnya berubah?

Tidak. Halaman disalin, bukan dirender ulang, jadi teks, gambar, dan font sama persis dengan aslinya dan teks tetap bisa dicari.

Bisakah mengambil halaman yang sama dua kali atau dengan urutan lain?

Setiap halaman hanya muncul sekali di ZIP dan diberi nama sesuai nomor halaman aslinya. Gunakan Atur Halaman untuk menggandakan atau mengubah urutan.

Bagaimana dengan PDF berkata sandi?

Masukkan kata sandinya saat diminta. File hasil ekstrak tidak memakai kata sandi.

Apakah bookmark dan komentar ikut?

Komentar dan sorotan di halaman ikut terbawa. Bookmark tidak ikut karena setiap hasil adalah file baru.

Apakah file saya di-upload ke server?

Tidak. Semua proses berjalan di browser, di perangkat Anda sendiri. Dokumen tidak pernah dikirim ke server mypdf.id maupun pihak lain.

Apakah bisa dipakai di HP?

Bisa, di Chrome, Safari, atau browser modern lain di Android maupun iPhone. Untuk file besar, laptop atau komputer akan terasa lebih cepat.
