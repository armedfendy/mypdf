Atur halaman PDF di mypdf.id: ubah urutan halaman dengan seret dan lepas, gandakan halaman, atau hapus yang tidak perlu dalam satu tampilan. Cocok untuk merapikan hasil scan yang urutannya acak. Gratis, tanpa daftar, dan file tidak di-upload.

Cara Mengatur Halaman PDF

1

Pilih file PDF

Klik kotak di atas atau seret satu file PDF. Semua halaman tampil sebagai thumbnail.

2

Susun ulang halaman

Seret thumbnail ke posisi baru. Bisa juga tulis urutan baru di kolom urutan halaman, misalnya 3, 1, 2, 4, lalu klik Terapkan.

3

Gandakan atau hapus halaman

Tombol hijau menggandakan halaman tepat di sebelahnya. Tombol merah menghapus halaman dari hasil akhir.

4

Simpan dan unduh

PDF dengan susunan baru tersimpan dengan nama file aslinya.

Tips Mengatur Halaman

  • Kolom urutan halaman harus menyebut setiap halaman tepat satu kali. Untuk menggandakan atau membuang halaman, pakai tombol di thumbnail.
  • Butuh beberapa salinan lembar formulir kosong? Klik tombol gandakan berulang kali.
  • Untuk menyusun halaman dari beberapa file sekaligus, gunakan Gabung PDF dalam mode halaman.

Pertanyaan Seputar Atur Halaman PDF

Bagaimana memindahkan halaman ke posisi lain?

Seret thumbnail halaman ke tempat baru. Untuk mengubah urutan seluruh dokumen sekaligus, tulis urutan baru di kolom urutan halaman, misalnya 3, 1, 2, 4.

Kenapa urutan yang saya tulis ditolak?

Kolom urutan harus berisi setiap nomor halaman asli tepat satu kali. Urutan 3, 1 (ada yang hilang) atau 1, 1, 2 (ada yang dobel) akan ditolak.

Bisakah menggandakan satu halaman beberapa kali?

Bisa. Setiap klik tombol gandakan menambah satu salinan tepat setelah halaman itu, dan setiap salinan bisa dipindahkan sendiri-sendiri.

Apakah kualitas halaman berubah?

Tidak. Halaman disalin apa adanya, jadi teks tetap bisa dipilih dan gambar tetap dengan resolusi aslinya.

Bisakah mengatur halaman dari beberapa PDF sekaligus?

Alat ini bekerja pada satu file. Untuk menyusun halaman dari beberapa file, gunakan Gabung PDF dalam mode halaman.

Apakah bookmark tetap ada?

Isi halaman, gambar, dan anotasi tetap utuh. Bookmark (daftar isi di panel samping) tidak ikut terbawa karena file baru disusun dari salinan halaman. Bila perlu, tambahkan lagi dengan alat Bookmark.

Apakah file saya di-upload ke server?

Tidak. Semua proses berjalan di browser, di perangkat Anda sendiri. Dokumen tidak pernah dikirim ke server mypdf.id maupun pihak lain.

Apakah bisa dipakai di HP?

Bisa, di Chrome, Safari, atau browser modern lain di Android maupun iPhone. Untuk file besar, laptop atau komputer akan terasa lebih cepat.
