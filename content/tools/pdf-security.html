Pertanyaan yang Sering Diajukan

Apa beda kata sandi dan pembatasan izin?

Kata sandi pengguna yang dipasang dengan Kunci PDF wajib dimasukkan untuk membuka file. Izin mengatur apa yang boleh dilakukan setelah file dibuka, seperti mencetak, menyalin, dan mengedit. Ubah Izin memungkinkan Anda memilih setiap izin satu per satu.

Seberapa kuat perlindungan kata sandinya?

Kunci PDF dan Ubah Izin memakai enkripsi AES 256-bit sesuai standar PDF 2.0. Enkripsinya praktis tidak bisa dibobol, jadi titik lemahnya ada pada kata sandi: gunakan kata sandi panjang dan kirimkan lewat jalur berbeda dari file.

Bisakah menghapus password PDF yang tidak saya ketahui?

Tidak. Buka Kunci PDF memerlukan kata sandinya, dan tidak ada alat di sini yang membobol kata sandi. Untuk file yang bisa dibuka tetapi tidak bisa dicetak atau disalin, gunakan Hapus Pembatasan.

Apa beda Tanda Tangan PDF dan tanda tangan digital?

Tanda Tangan PDF menempelkan gambar tanda tangan yang digambar, diketik, atau diunggah. Tanda Tangan Digital memakai sertifikat X.509 Anda (.pfx, .p12, atau .pem) untuk membuktikan siapa yang menandatangani dan bahwa file tidak diubah sesudahnya.

Bagaimana menyensor teks agar benar-benar hilang?

Gunakan fitur redaksi di Edit PDF, yang menghapus isi di area yang ditandai, bukan sekadar menutupinya. Bila properti dokumen, komentar, atau lampiran bisa membocorkan informasi yang sama, jalankan juga Hapus Metadata atau Sanitasi PDF.

Apa beda Hapus Metadata dan Sanitasi PDF?

Hapus Metadata hanya membuang properti dokumen seperti judul, penulis, tanggal, dan aplikasi pembuat. Sanitasi PDF bisa juga meratakan formulir dan menghapus anotasi, JavaScript, lampiran, layer, dan tautan. Keduanya tidak bisa dibatalkan, jadi simpan file aslinya.

Apa fungsi meratakan (flatten) PDF?

Ratakan PDF menyatukan isian formulir dan anotasi ke dalam halaman sehingga tampilannya sama tetapi tidak bisa diubah lagi. Gunakan setelah formulir diisi atau tanda tangan ditempel, sebelum file dikirim.

Apakah kata sandi, sertifikat, atau file saya dikirim ke server?

Tidak. Mengunci, membuka kunci, membersihkan, dan menandatangani berjalan di browser Anda. Satu-satunya pengecualian adalah Tanda Tangan Digital, yang mungkin menghubungi server penerbit sertifikat untuk mengambil rantai sertifikat; dokumennya sendiri tetap tidak dikirim.
