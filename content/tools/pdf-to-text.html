Ubah PDF ke teks di mypdf.id: ambil seluruh teks dari PDF menjadi file .txt yang mudah disalin, dicari, atau diolah. Bisa beberapa file sekaligus. Gratis, tanpa daftar, dan dokumen tidak di-upload ke server.

Cara Mengambil Teks dari PDF

1

Pilih file PDF

Klik kotak di atas atau seret satu atau beberapa PDF.

2

Klik Ekstrak

Teks di setiap halaman dibaca dari kiri ke kanan, atas ke bawah.

3

Unduh file teks

Satu PDF menghasilkan satu file .txt dengan nama yang sama. Beberapa PDF diunduh sekaligus dalam satu ZIP.

Kalau Hasilnya Kosong atau Berantakan

  • File .txt kosong biasanya berarti PDF hasil scan yang tidak punya lapisan teks. Jalankan OCR PDF; alat itu juga bisa langsung mengunduh teksnya.
  • Dokumen berkolom, tabel, dan kotak samping bisa tercampur urutannya. Untuk tabel, gunakan PDF ke Excel.
  • Format seperti huruf tebal, judul, dan gambar tidak ikut, karena hasilnya teks biasa.

Pertanyaan Seputar PDF ke Teks

Kenapa file .txt saya kosong?

PDF kemungkinan hasil scan atau foto yang tidak punya lapisan teks. Jalankan OCR PDF lebih dulu.

Apakah urutan teksnya benar?

Untuk dokumen satu kolom umumnya benar. Dokumen berkolom, tabel, dan kotak samping bisa tercampur, dan header, footer, serta nomor halaman ikut terambil.

Apakah format tulisan ikut?

Tidak. Hasilnya teks biasa UTF-8, jadi huruf beraksen dan aksara lain tetap terbaca, tetapi huruf tebal, judul, tautan, dan gambar tidak ikut.

Bisakah mengambil teks dari beberapa PDF sekaligus?

Bisa. Setiap PDF menjadi file .txt sendiri dan semuanya diunduh dalam satu ZIP.

Bisakah hanya halaman tertentu?

Alat ini selalu mengambil semua halaman. Ambil dulu halamannya dengan Ekstrak Halaman, lalu ubah file hasilnya.

Apakah file saya di-upload ke server?

Tidak. Semua proses berjalan di browser, di perangkat Anda sendiri. Dokumen tidak pernah dikirim ke server mypdf.id maupun pihak lain.

Apakah bisa dipakai di HP?

Bisa, di Chrome, Safari, atau browser modern lain di Android maupun iPhone. Untuk file besar, laptop atau komputer akan terasa lebih cepat.
