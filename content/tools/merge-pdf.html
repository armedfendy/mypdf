Cara Menggabungkan PDF Online

1

Pilih file PDF

Klik kotak di atas atau seret beberapa file PDF sekaligus. Anda juga bisa menambahkan gambar JPG atau PNG, yang otomatis diubah menjadi halaman PDF.

2

Atur urutannya

Seret file ke atas atau ke bawah. Butuh urutan per halaman? Pilih Mode Halaman lalu susun thumbnail halamannya satu per satu.

3

Klik Gabungkan PDF

Semua file digabung di browser Anda dalam hitungan detik, tanpa di-upload ke server.

4

Unduh hasilnya

File gabungan langsung tersimpan di perangkat Anda, gratis dan tanpa watermark.

Kapan Perlu Menggabungkan PDF?

Banyak portal pendaftaran hanya menerima satu file untuk satu persyaratan. Dengan menggabungkan PDF, beberapa dokumen bisa dikirim sebagai satu file yang rapi. Contoh yang sering dibutuhkan:

  • Menyatukan scan KTP, Kartu Keluarga, ijazah, dan transkrip untuk pendaftaran CPNS, PPPK, beasiswa, atau lamaran kerja.
  • Menggabungkan bab-bab skripsi, laporan, atau proposal yang dikerjakan terpisah menjadi satu dokumen utuh.
  • Menyatukan invoice, kuitansi, dan bukti transfer untuk laporan keuangan atau klaim penggantian biaya.

Kalau ukuran file gabungan melebihi batas unggah portal (misalnya 1 MB atau 200 KB), lanjutkan dengan Kompres PDF atau Kompres PDF ke 200 KB.

Pertanyaan Seputar Gabung PDF

Apakah file PDF saya di-upload ke server saat digabungkan?

Tidak. File digabungkan di dalam browser Anda dengan modul WebAssembly CoherentPDF, lalu hasilnya langsung disimpan ke perangkat Anda. Dokumen seperti KTP, kontrak, atau rekening koran tidak pernah meninggalkan perangkat Anda.

Bisakah saya menggabungkan hanya beberapa halaman dari setiap file?

Bisa. Di Mode File, tulis rentang seperti 1-3, 5 di kotak Halaman pada file tersebut, atau kosongkan untuk mengambil semua halaman. Di Mode Halaman, setiap halaman tampil sebagai thumbnail yang bisa diseret ke urutan mana pun, termasuk menyelipkan halaman dari dokumen berbeda.

Bagaimana urutan file di hasil gabungan?

Sesuai urutan di daftar, dari atas ke bawah. Seret file untuk mengubah urutan sebelum menggabungkan, dan gunakan Tambah Lebih Banyak File untuk menambah dokumen tanpa mengacak urutan yang sudah ada.

Apakah bookmark di PDF asli tetap ada?

Ya. Bookmark setiap file ikut dibawa ke dokumen gabungan sehingga daftar isinya tetap bisa dipakai. Isi halaman dan anotasi disalin apa adanya.

Kenapa ukuran file gabungan besar?

Font dan gambar dari setiap file disalin apa adanya, jadi ukurannya kira-kira jumlah dari semua file. Centang Hapus font duplikat untuk menyatukan font yang sama, lalu kecilkan lagi hasilnya dengan alat Kompres PDF bila perlu.

Bisakah menggabungkan PDF dengan ukuran halaman berbeda?

Bisa. Setiap halaman mempertahankan ukuran dan orientasinya, jadi halaman A3 lanskap bisa berada setelah halaman A4 potret tanpa diubah skalanya. Untuk menyeragamkan ukuran, gunakan alat Perbaiki Ukuran Halaman setelah digabung.

Bisakah menggabungkan PDF yang dilindungi kata sandi?

Bisa, selama Anda tahu kata sandinya. Alat ini akan memintanya saat file ditambahkan, lalu menggabungkan halaman yang sudah dibuka. File hasil gabungan tidak berkata sandi; tambahkan lagi dengan alat Lindungi PDF bila diperlukan.

Apakah bisa dipakai di HP?

Bisa, di Chrome, Safari, atau browser modern lain di Android maupun iPhone. Untuk menggabungkan banyak file berukuran besar, laptop atau komputer akan terasa lebih cepat karena memorinya lebih besar.
