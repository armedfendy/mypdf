Dokumen PDF sering berisi hal yang tidak untuk dibaca sembarang orang: kontrak, slip gaji, laporan keuangan, atau data pribadi. Memberi kata sandi adalah cara paling sederhana untuk melindunginya sebelum dikirim lewat email atau aplikasi pesan. Sebaliknya, kadang Anda perlu menghapus kata sandi dari file milik sendiri, misalnya karena portal atau aplikasi arsip menolak file yang terenkripsi.

Panduan ini membahas keduanya, memakai [Kunci PDF dengan Password](/protect-pdf) dan [Buka Kunci PDF](/unlock-pdf) di mypdf.id.

## Cara mengunci PDF dengan password

1. Buka [Kunci PDF dengan Password](/protect-pdf), lalu pilih atau seret satu file PDF.
2. Isi **kata sandi pengguna**. Ini wajib, dan harus diketik siapa pun yang ingin membuka file.
3. Isi **kata sandi pemilik** bila Anda juga ingin membatasi hal yang boleh dilakukan penerima (opsional, dan harus berbeda dari kata sandi pengguna).
4. Unduh PDF yang sudah terkunci.

File dienkripsi dengan AES 256-bit, standar enkripsi PDF 2.0. Prosesnya berjalan di browser Anda, sehingga file dan kata sandi tidak dikirim ke server.

## Kata sandi pengguna dan kata sandi pemilik

Dua jenis kata sandi ini sering tertukar.

- **Kata sandi pengguna** dipakai untuk membuka dokumen. Tanpa itu, isi PDF tidak bisa dibaca.
- **Kata sandi pemilik** mengatur izin. Bila diisi dengan kata sandi yang berbeda, orang yang membuka PDF memakai kata sandi pengguna tidak bisa mencetak, menyalin teks, mengedit, atau mengubah halaman.

Kalau Anda hanya ingin pembaca bisa membuka dan membaca, cukup isi kata sandi pengguna. Kalau Anda ingin membatasi cetak dan salin tanpa meminta kata sandi untuk membuka, gunakan alat [Ubah Izin](/change-permissions).

## Tips membuat kata sandi yang kuat

- Pakai minimal 12 karakter, gabungan huruf besar dan kecil, angka, dan simbol. Kekuatan perlindungan bergantung pada kata sandi Anda.
- Hindari tanggal lahir, nama sendiri, atau nomor telepon.
- Kirim kata sandi lewat jalur yang berbeda dari file, misalnya lewat telepon atau pesan terpisah. Jangan kirim keduanya di email yang sama.
- Simpan kata sandi di pengelola kata sandi, bukan di kertas yang mudah hilang.
- Simpan salinan PDF asli tanpa kata sandi untuk arsip pribadi.

## Kalau lupa kata sandi

Tidak ada cara memulihkan kata sandi yang hilang, oleh siapa pun, termasuk kami. mypdf.id tidak menyimpan file maupun kata sandi Anda. Karena itu salinan asli yang tidak terkunci sangat penting.

## Cara menghapus password dari PDF milik sendiri

Gunakan [Buka Kunci PDF](/unlock-pdf).

1. Pilih satu atau beberapa PDF. Beberapa file bisa diproses sekaligus bila kata sandinya sama.
2. Masukkan kata sandi, baik kata sandi untuk membuka file maupun kata sandi pemilik.
3. Klik tombol buka kunci. Enkripsi dihapus seluruhnya.
4. Unduh hasilnya. Satu file diunduh dengan nama aslinya, beberapa file diunduh dalam satu ZIP.

Isi dokumen tidak berubah. Halaman, teks, gambar, formulir, dan bookmark tetap utuh. Hanya lapisan enkripsinya yang dihapus. Kata sandi saat ini tetap diperlukan: alat ini tidak membobol, menebak, atau mencoba-coba kata sandi.

## Kapan perlu menghapus password?

- Portal atau aplikasi arsip menolak file yang terenkripsi.
- PDF terkunci perlu digabung dengan file lain lewat [Gabung PDF](/merge-pdf).
- Dokumen akan diarsipkan jangka panjang dan kata sandinya tidak diperlukan lagi.

## PDF yang bisa dibuka tapi tidak bisa dicetak atau disalin

Ini kasus berbeda. PDF seperti ini tidak meminta kata sandi untuk dibuka, tetapi memasang batasan izin. Untuk dokumen milik Anda atau yang Anda berhak memakainya, gunakan [Hapus Pembatasan](/remove-restrictions). Alat ini ditujukan untuk keperluan wajar, misalnya mencetak formulir sendiri atau menyalin kutipan untuk catatan. Jangan memakainya untuk melanggar hak cipta atau lisensi orang lain.

## Setelah dikunci

- Bila perlu menandatangani lebih dulu, lakukan sebelum mengunci: [Tanda Tangan PDF](/sign-pdf).
- Bila ukuran file perlu dikecilkan, lakukan sebelum mengunci dengan [Kompres PDF](/compress-pdf), agar Anda tidak perlu membuka kunci ulang hanya untuk mengubah ukuran.
