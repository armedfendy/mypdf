Menyatukan beberapa PDF menjadi satu file adalah salah satu pekerjaan paling sering dilakukan. Entah untuk melengkapi berkas pendaftaran, menyusun laporan dari beberapa bagian, atau mengirim kumpulan bukti transaksi, satu file yang rapi jauh lebih mudah dikirim dan dibaca daripada lima atau enam lampiran terpisah.

Panduan ini memakai [Gabung PDF](/merge-pdf) di mypdf.id. Alatnya gratis, tanpa watermark, dan file Anda diproses di browser tanpa di-upload.

## Langkah menggabungkan PDF

1. Buka [Gabung PDF](/merge-pdf), lalu pilih atau seret beberapa file sekaligus. Gambar JPG atau PNG juga bisa dimasukkan dan otomatis menjadi halaman PDF.
2. Atur urutan dengan menyeret file ke atas atau ke bawah. Urutan di daftar sama dengan urutan di hasil akhir.
3. Klik tombol gabung. Prosesnya berlangsung di browser dan biasanya selesai dalam hitungan detik.
4. Unduh file gabungannya.

## Dua mode: file atau halaman

**Mode File** menggabungkan seluruh file sesuai urutan daftar. Cocok untuk kasus sederhana. Bila hanya butuh sebagian halaman dari satu file, tulis rentangnya, misalnya `1-3, 5`, atau kosongkan untuk mengambil semua halaman.

**Mode Halaman** menampilkan setiap halaman sebagai thumbnail yang bisa diseret ke posisi mana pun. Berguna kalau Anda perlu menyelipkan satu halaman dari dokumen B di tengah dokumen A.

## Kapan perlu menggabungkan PDF?

- **Berkas pendaftaran.** Banyak portal hanya menerima satu file per persyaratan. Satukan scan KTP, Kartu Keluarga, ijazah, dan transkrip jadi satu dokumen.
- **Skripsi dan laporan.** Bab yang dikerjakan terpisah dapat disatukan jadi dokumen utuh.
- **Keuangan.** Gabungkan invoice, kuitansi, dan bukti transfer untuk laporan atau klaim biaya.
- **Presentasi dan materi.** Satukan beberapa handout jadi satu bahan bacaan.

## Foto dan scan berformat gambar

Kalau dokumen Anda masih berupa foto, tidak perlu diubah satu per satu. Masukkan saja gambar JPG atau PNG ke daftar, dan alat akan membuatnya jadi halaman PDF. Atau ubah dulu dengan [JPG ke PDF](/jpg-to-pdf) bila perlu mengatur ukuran halaman.

## Merapikan hasil gabungan

Setelah digabung, Anda masih bisa membenahi:

- [Atur Halaman](/organize-pdf) untuk mengurutkan ulang, menggandakan, atau menghapus halaman.
- [Hapus Halaman](/delete-pages) untuk membuang halaman kosong atau yang tidak diperlukan.
- [Putar PDF](/rotate-pdf) bila ada halaman scan yang miring atau terbalik.
- [Nomor Halaman](/page-numbers) untuk memberi penomoran yang konsisten di seluruh dokumen.

## Ukuran file terlalu besar?

Ukuran hasil gabungan kira-kira sama dengan jumlah semua file, karena gambar dan font ikut disalin. Bila melebihi batas unggah portal, kecilkan dengan [Kompres PDF](/compress-pdf) atau pakai halaman dengan target khusus seperti [Kompres PDF ke 1 MB](/compress-pdf-to-1mb). Di pengaturan gabung, opsi menghapus font duplikat juga bisa membantu menyusutkan ukuran.

## Bookmark dan ukuran halaman

Bookmark dari tiap file ikut dibawa ke dokumen gabungan, sehingga daftar isi tetap berguna. Halaman dengan ukuran berbeda, misalnya A4 potret dan A3 lanskap, dipertahankan apa adanya tanpa diubah skalanya.

## Tetap di perangkat Anda

Dokumen yang digabung sering berisi data pribadi. Di mypdf.id penggabungan dilakukan di browser Anda, jadi file tidak pernah diunggah ke server kami. Hasilnya langsung tersimpan di perangkat Anda.
